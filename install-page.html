voice-ime

Linux 上的语音输入：长按 Ctrl+Alt 说话，松开后文字进入当前输入框。它不占输入法位，拼音输入法可以一直保持激活。

01
Background

为什么做这个

Windows 上不缺语音输入法：豆包输入法、微信输入法都免费，识别准，没有广告，装上就能用。Linux 这边这条路是断的——这些产品都没有 Linux 版，云桌面上更没有现成可用的选择。

而日常办公的云桌面恰恰是 NSDL 这类 Linux 系统，语音输入就只能空着。等厂商支持不知道要等到什么时候，那就自己补上这一段。

语音识别本身已经有可用的云服务（火山引擎豆包 SeedASR），缺的只是把「按住说话」接到桌面输入框的那一截。这个插件做的就是这一截：fcitx 的一个 addon，几十 KB。

  • 不替换输入法：拼音输入法保持激活，语音是叠加能力，不用来回切。
  • 不经过剪贴板：识别结果走 fcitx 提交接口，直接进入光标处。
  • 只送按住期间的音频：按下到松开这一段的 16 kHz 单声道，别的不上传。

03
After install

装好之后

操作结果
长按 Ctrl+Alt（≥0.3 秒）开始录音，松开后停止并把识别结果写入光标处
Ctrl+Alt+Space持续对话：松手后继续说，按 Esc 结束
录音中单按 Ctrl / 空闲时按三个键打开草稿窗，先攒文字再决定怎么发
拼音打字照常，不需要切输入法

前提：fcitx 处于激活态（fcitx-remote 返回 2）。
